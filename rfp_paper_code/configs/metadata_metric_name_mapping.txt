# Python <-> BQ metric name mapping
# Complete mapping between DataValues attribute names and BQ column names
#
# Four columns: datavalues_name | db_name | phase2fp | combination_metric
#
#   phase2fp:           1 if metric is used by a phase-2 fingerprinter (AkamaiV2, FPJSv2,
#                         Signifyd), including both combination metrics and their components
#   combination_metric: 1 if metric is a combined hash of other individual metrics
#
# Naming conventions:
#   hw_*            -> * (prefix stripped)         e.g. hw_camera_count -> camera_count
#   intl_*          -> * (prefix stripped)         e.g. intl_timezone -> timezone
#   screen_*        -> * (media query booleans)    e.g. screen_monochrome -> monochrome
#   font_prefcolor_ -> color_*                     e.g. font_prefcolor_canvas -> color_canvas
#   font_prefmodified_ -> font_*_modified          e.g. font_prefmodified_default -> font_default_modified
#   canvas_canvasdata01 -> canvasdata1             (strip prefix, remove zero-pad)
#   canvassoftware_*01  -> canvasdata1software     (strip prefix, append software)
#   webgl_renderer  -> gl_renderer                 (webgl_ -> gl_, webgl2_ -> gl2_)
#   mathml_1        -> mathml1                     (underscore removed)
#   screen_web_*_width -> *_width                  (screen_web_ stripped)
#
